# О.К. фитнес — сайт студии йоги и пилатеса

Многостраничный сайт студии в Минске (просп. Дзержинского, 21): главная, занятия, о студии, запись и как найти. Тёплые коричневые и песочные тона, органичные формы, шрифты Prata и Raleway. Чистые HTML, CSS и JS без сборки.

## Что менять
Всё в `js/data.js`: `SITE` (адрес, телефон, Instagram), `FORMATS` (форматы занятий), `PRICES` (стоимость). Пока `PRICES` пустой, на сайте написано «уточняйте». Строка цены: `[занятие, цена, пояснение]`.

## Публикация на GitHub Pages
Залей содержимое папки в корень репозитория (не `.zip`), затем **Settings → Pages → Deploy from a branch → `main` / `(root)`**.
